PROJECT 1
Reducing Post-Order Cancellations via Assurance Messaging
01 // Problem
The Cancellation Window Problem

Food delivery platforms experience a disproportionate number of cancellations within the first few minutes after an order is placed. While operational factors contribute to cancellations, a significant portion originates from user uncertainty immediately after purchase.

The challenge is not transaction completion.

The challenge is post-purchase confidence.

How can a platform reduce preventable cancellations without introducing friction into the ordering flow?

02 // Context & Boundaries

Industry
Food Delivery & Quick Commerce

Focus Area
Post-Purchase Experience

User Segment
Users placing food orders through mobile applications

Constraint
No changes to checkout flow, pricing, promotions, or delivery operations

Scope
Behavioral intervention within the first few minutes after order placement

03 // Key Observations
Observation 1

Many cancellations occur before any operational issue has actually occurred.

Observation 2

Users often experience uncertainty immediately after spending money online.

Observation 3

The period immediately after checkout creates a psychological vulnerability where doubt can override initial purchase intent.

Core Insight

The problem is not always service failure.

The problem can be perceived uncertainty.

A timely reassurance message may reduce cancellation behavior before it occurs.

04 // Behavioral Analysis

The proposed solution was based on three behavioral principles:

Progress Signaling

Users become less likely to abandon a process when they perceive meaningful progress.

Commitment Effect

Once users feel committed to a purchase decision, reversal becomes less likely.

Reduced Uncertainty

Clear communication lowers anxiety associated with waiting periods.

The intervention targeted the "regret window" immediately after order placement where cancellation probability is highest.

05 // Strategic Insight

The most scalable cancellation reduction opportunity may not come from operational improvements.

It may come from reducing uncertainty before dissatisfaction develops.

A lightweight messaging intervention can influence behavior at significantly lower cost than logistics optimization initiatives.

06 // Proposed Intervention
Assurance Messaging

Display a contextual reassurance message immediately after order confirmation.

Example Objectives:

Reinforce order progress
Increase confidence
Reduce purchase regret
Improve perceived reliability
Experiment Design

Method:
A/B Test

Control:
Existing confirmation experience

Variant:
Confirmation experience with assurance messaging

Primary Goal:
Measure reduction in early-stage cancellations.

07 // Success Metrics
North Star

10-Minute Cancellation Rate

Supporting Metrics
Overall cancellation rate
Customer support contacts
Repeat order rate
User retention
Order completion rate
Guardrails
No negative impact on user trust
No increase in customer complaints
No degradation of post-order experience
08 // Retrospective Learnings

Behavioral design opportunities often exist in overlooked moments of the customer journey.

Small interventions can create measurable business impact when deployed at psychologically sensitive decision points.

Not every growth problem requires a new feature.

Sometimes it requires a better message.

PROJECT 2
Learning Execution System
01 // Problem
The Last-Mile Problem of Learning

Students rarely fail because information is unavailable.

They fail because execution is inconsistent.

Despite unprecedented access to educational content, completion rates remain low and many learners abandon programs before achieving meaningful outcomes.

How can a system remove planning friction and increase learning consistency?

02 // Context & Boundaries

Industry
Education Technology

Target Users
Students pursuing long-term academic or professional goals

Focus
Learning Execution

Constraint
No creation of additional educational content

Strategic Scope
Improve adherence rather than content quality

03 // Key Observations
Observation 1

Students spend substantial effort deciding what to study.

Observation 2

Learning platforms optimize content delivery but not execution.

Observation 3

Planning overhead creates significant decision fatigue.

Core Insight

Consistency fails not because students lack motivation.

Consistency fails because they face too many micro-decisions before beginning work.

04 // Root Cause Analysis

The project identified three primary barriers:

Ambiguity

Goals exist without actionable next steps.

Friction

Starting work requires excessive activation energy.

Blindness

Progress remains difficult to visualize.

Together these factors create an execution gap between intention and action.

05 // Strategic Insight

Most EdTech products compete on content.

The greater opportunity may exist within execution infrastructure.

A system that reduces planning burden and automates task generation can improve adherence independent of content quality.

06 // Proposed Solution
Learning Execution System

A structure-first platform designed to convert educational content into executable daily actions.

Core Components

Content → Tasks
Convert learning material into actionable micro-tasks.

Zero-Decision Framework
Remove planning decisions from learners.

Execution Layer
Focus on adherence rather than content discovery.

User Flow

Upload Material

↓

Define Goal

↓

System Creates Schedule

↓

Execute Daily Tasks

↓

Track Progress & Reinforce Habits

07 // Success Metrics
North Star

Learning Adherence Rate

Supporting Metrics
Daily task completion
Retention after 30 days
Weekly active learners
Learning streak length
Goal completion rate
Business Metrics
Subscription retention
Customer lifetime value
Completion-driven engagement
08 // Retrospective Learnings

Planning and execution are fundamentally different problems.

Most productivity systems assume users can consistently self-organize.

The proposed system instead treats planning as a service and execution as the primary product experience.
